# 愿景与边界

Status: Accepted (product direction)

Raminga 是一个完整的 P2P 社交网络，其基本实体是 **Raminga Node**。节点可以独立存在、保存本地信息、对外提供可见档案，并通过获授权的操作者（人类、客户端或 AI Agent）参与社交或娱乐。

## 原则

1. Node-first：核心网络与社交功能不依赖内置智能体、DSH 或单一运营商。
2. 数据自主：节点拥有可迁移的本地数据、身份和档案；对外共享依照明确的权限范围。
3. 开放互操作：网络协议独立于官方代码、编程语言、客户端和 AI 框架；第三方可以自行实现并运行兼容节点。
4. 公共服务可替换：发现、中继、缓存、索引和推荐可以提供便利，但不构成唯一事实来源。
5. 安全默认收紧：远端信息不可信，操作他人节点或访问非公开资料必须通过授权。
6. 无官方准入门槛：参与公共协议不要求申请官方许可、账号或 API Key，也不要求使用官方客户端、唯一官方引导/中继或向官方注册节点。

## 开放网络与节点自治

Raminga 官方实现只是协议的一种实现，不享有特殊网络信任或优先权限。能够证明符合协议并具有可达通信路径的非官方节点，在协议层面应与官方节点平等；单个节点仍可基于本地策略拒绝连接、阻止滥用、限制可见内容或撤销授权。

Apache-2.0 规范官方**代码的再利用**，而第三方能够独立**加入网络**取决于公开可实现的协议、替代发现/中继路径和互操作测试。开放接入不是保证任意节点随时可达，也不授予访问私人档案或代为操作节点的权限。

## 非目标（当前阶段）

不把 Resident Agent、AI 宠物玩法、内容推荐平台、商业订阅后台、移动客户端或完整游戏世界作为节点核心或必需功能。AI 宠物是可选扩展，可以依赖 DSH 插件存在，但节点不内置、也不要求用户使用它。内容发布是节点的必选能力；DSH、AI 宠物和托管服务永远不是使用 Raminga 的前提。

## 现实约束

完全 P2P 不代表网络不需要任何在线协助：NAT、离线投递、陌生节点发现可能需要可替换的在线服务。离线节点不保证可访问；关闭默认服务后已有本地数据可用，通信仍需要可达路径。
