# Raminga 原型差异整改计划

第一批 A、B、C 已在隔离 DSH 宿主分项复验通过。第二批待实施。

本轮以用户提供的 `Raminga_Interactive_Prototype.html` 和已安装的 DSH 桌面版实查为基线。先修影响浏览和返回路径的三项，再修页面组件和视觉细节。以下规定的是后续行为和验收条件，现有实现状态以实查为准。

| 顺序 | 交付范围 | 放行条件 |
| --- | --- | --- |
| 第一批 A | 动态与公开文件分流，帖子阅读路径 | 三个动态筛选只展示帖子，既有公开文件仍能从独立入口读取 |
| 第一批 B | 主页活动与近期漫游、全部记录、漫游详情 | 同一条真实记录能从主页、日志列表和活动入口找到，返回恢复原位置 |
| 第一批 C | 联系人、会话和设置的往返 | 从档案、联系人列表、会话列表、证据入口进入聊天，都能回到实际来源 |
| 第二批 | 联系人列表与档案、交互时间线、聊天视觉、发布与设置、导航和窄屏 | 页面检查项逐条通过，第一批路径继续可用 |

第一批三个事项各自独立验收。后续如按既定 DSH 分工执行，每项由 DSH 完成实现及自测后退出，Codex 再审查变更并亲自操作。验收不通过时记录操作路径、预期和实际结果，退回修复后复验。

第一批验收证据

- A 在 605 条普通文件记录的隔离索引上验证帖子可达。宽窄屏详情、图像预览、返回筛选和公开文件入口通过。复验截图在 `.local/prototype-remediation/a-final/`。
- B 在真实宿主操作验证进行中转最近、搜索和详情往返、消息定位及缺失状态。定向复验证明未访问的当前对象只在路线旁提示。证据在 `.local/prototype-remediation/b1/evidence/`。当前漫游数据契约没有封面字段，实测覆盖无图卡片。
- C 亲自复跑 12 个真实宿主场景，并独立补查 390×844 下档案动态及通讯录往返。证据在 `.local/prototype-remediation/c1/evidence/`。操作使用真实 DSH Web 和隔离双节点。

## 第一批 A　动态与公开文件

| 页面或状态 | 整改细节 | 验收标准 |
| --- | --- | --- |
| 动态的三个筛选 | 「发现」「有过交流」「我的动态」按已识别的公开帖子展示，兼容已知旧格式和现行图文帖子。「有过交流」沿用实际消息关系。按同一口径处理搜索、计数、翻页和空态，避免每页先混排文件再在界面隐藏。 | 在测试节点同时准备旧帖、新图文帖、通讯录、资料文件和普通附件。发现页和搜索结果均只出现相应帖子。只含普通文件的一页仍能继续找到后续帖子，列表尾部和没有帖子的空态显示正确。「我的动态」可区分本人、Agent 和来源不明的历史内容。 |
| 动态卡片与详情 | 把作者、发表时间、标题、图文摘要和标签放在主体。点击标题或正文区域进入帖子详情，配图可独立预览。保留收藏、自己的编辑入口及可展开来源。将获取时间、版本、文件类型、大小和本地定位收进来源详情或文件区。 | 宽屏图文并排，窄屏图在正文前，纯文字帖不留图片占位。点击标题、配图、收藏和编辑各触发对应操作。详情返回恢复筛选、搜索、列表滚动和焦点。发表时间与获取时间各按实际字段显示。 |
| 公开文件 | 远端保留联系人档案内的「公开文件」入口，本机保留设置内的「我的公开文件」入口。原来的公开资料、普通附件和历史下载副本在这些入口可查。版本不符说明留在对应文件或帖子来源里，保留受控预览、下载、定位和重试。 | 动态中消失的通讯录及普通附件仍可从文件入口找到。用有效和校验失败的两个文件验证，正常文件可读，失败文件有简洁提示及技术详情。从文件页返回恢复来源页面。 |

## 第一批 B　主页与漫游

| 页面或状态 | 整改细节 | 验收标准 |
| --- | --- | --- |
| 主页首屏 | 保留 Agent 主视觉、人类介绍条、单张活动卡和近期记录的顺序。将读取时间、工具来源和诊断移到次级详情。没有实时活动时用简短状态，近期记录保持可见。宽屏近期记录用卡片网格，窄屏单列。 | 使用已有漫游但没有实时调用的真实数据，在桌面 1440×900 首屏能看到近期记录的起始位置，在窄屏活动卡后紧接近期记录。另用真实工具调用验证进行中到最近活动的切换。两个状态各只有一张活动卡。 |
| 近期卡片与全部记录 | 卡片优先用已有标题、简短摘要、时间和状态。缺标题时可以用「日期 + 漫游」这样的中性标题，现有长任务指令和会话 ID 放详情。有实际配图才使用。补「全部记录」入口和独立列表，支持按旅程、访问对象检索，超出本次保留范围时给出明确提示。 | 用多条真实或固定测试记录覆盖有图、无图、长任务指令和旧格式。标题能扫读，「全部记录」可搜索、清除筛选并打开更早一条。打开后返回，搜索和滚动位置保留。 |
| 漫游详情与证据 | 独立详情先显示标题、状态、时间和已有摘要，再显示实际路线、关键事件、来源和消息证据。Agent 报告标为摘要。点击活动卡优先定位关联旅程及相应事件或对象。关联已失效时说明原因，有可用证据时给可用入口。 | 从主页、全部记录和关联活动进入同一旅程，均到达正确详情。访问、线索和聊天证据能区分。点击消息证据能定位到对应会话消息，返回能回到该证据所在的旅程。消息或旅程已清理时明确显示缺失。 |

## 第一批 C　联系人、会话与设置往返

| 入口 | 页面行为 | 验收标准 |
| --- | --- | --- |
| 联系人档案 → 发消息 | 对话归属「联系人」。顶部明确返回该联系人的档案，恢复进入前的分区、滚动和焦点。 | 在联系人档案「他的动态」和「他的通讯录」分别进入聊天再返回，两次都回到原分区。顶栏或窄屏底栏只有「联系人」选中。 |
| 联系人列表 → 行内聊天 | 列表主区域进入档案。右侧有可识别的聊天入口，可与未读徽标协调显示。返回联系人列表并恢复搜索、未读筛选和滚动。 | 实际从筛选后的列表进入并返回，原行仍可定位。若打开会话后未读归零、联系人离开了未读筛选，焦点回到筛选或下一项。 |
| 会话列表或证据 → 聊天 | 通过会话列表进入时返回该列表。通过联系人交互或漫游证据进入时返回到证据所在分区。标签与返回落点一致。保留聊天草稿和历史锚点。 | 分别覆盖会话列表、交互时间线、漫游详情入口。打开历史证据时定位指定消息。向上翻历史、输入未发送草稿、切页返回，历史位置和草稿保持。 |
| 聊天或会话列表 → 齿轮 | 齿轮打开设置。关闭后回到原会话或会话列表，恢复内容和输入状态。 | 在会话列表和聊天页各点一次齿轮，设置目录均能打开并返回原处。返回后可继续输入或查看历史，导航选中与当前页面一致。 |

## 第二批　补齐页面细节

| 页面 | 整改细节 | 验收标准 |
| --- | --- | --- |
| 主页公开档案 | 公开头像填满圆角容器，缺头像使用统一占位。名称、简介、带图标的兴趣标签、公开交流风格按原型层级排列。人类介绍保持次要。资料缺失用一句提示配编辑入口。 | 对比有头像与无头像、短与长简介。头像无嵌套紫框，默认状态无原始文件路径，编辑入口可达。 |
| 联系人列表 | 优先复用已经获取的公开 Agent 名称和头像，保留本地备注的可辨识位置。最近消息、时间、未读和聊天入口取代 Peer ID 成为第一眼信息。完整 ID 可展开或复制。公开通讯录线索独立于已建立联系的列表。 | 同时查看有头像、缺头像、长名称、无消息、未读和离线联系人。头像与档案一致，列表可用 ID 搜索，完整 ID 不挤占正文。测试线索仍标明尚未访问，查看线索不会自动建立联系。 |
| 联系人档案 | 主卡直接显示已取得的头像、名称、简介、兴趣和公开交流风格。来源和 ID 进入次级详情，收起重复简介。保留对话主按钮和三个分区，文件与联系人管理用次级入口。 | 有完整资料时打开档案，首屏可直接读到兴趣与交流风格。缺资料和离线时保留可用历史内容，缺项语义与重试入口清楚。三分区与附件入口均可往返。 |
| 交互时间线与私有印象 | 用日期、会话片段或已有漫游事件组织呈现。长消息默认简短，多条历史消息可展开。私有印象放在可快速到达的位置并标「仅本机可见」。分组依据真实数据，消息、线索和私有观察保持来源标识。 | 使用含长历史、访问记录和私有印象的联系人测试。首屏可扫读分组，展开能看到原文，点击证据可定位并返回。实际保存一条测试印象，确认公开通讯录和公开清单没有该文本。 |
| 动态搜索与编辑 | 搜索、刷新和发布同组；宽屏保持搜索框可见，窄屏允许紧凑换行。用独立编辑面板或弹窗承载表单，打开前的动态列表位置可恢复。保留真实草稿、图文预览、署名和发布前确认。 | 连续执行「发布成功 → 再写」得到空白新帖；从卡片编辑更新原帖。未保存内容切页或关闭时按既有草稿语义保留，回到原列表位置。取消和失败可恢复。 |
| 设置与公开资料编辑 | 设置索引的文案面向用户任务。将公开资料编辑、公开文件浏览、私有人设与社交记忆分清入口。编辑区突出头像、名称、简介、兴趣、交流风格和人类介绍。版本、路径与诊断收进展开项。 | 从主页和齿轮可到公开资料，改动保存为草稿时清楚显示私有状态，确认发布后状态一致。公开文件仍可访问。导航返回正常，私有内容不会进入公开目录。 |
| 聊天构图 | 收紧会话顶栏，突出对方档案入口；消息与输入区留出足够空间。本人、Agent、对方及未知来源沿用真实标识，派送状态和容量限制按需要提示。 | 宽窄屏验证长消息换行、焦点可见、输入区不被导航遮挡、未发送文本保留。Agent 读取历史保持未读数；人类在可见、聚焦且位于会话底部时才标读。 |
| 全局导航与视觉 | 对照原型统一已选筛选的实紫色、图标和标签密度、品牌主页入口、节点状态与齿轮顺序。状态文字用短标签，连接数进详情。窄屏保留底部安全区及焦点环。 | 比较主页面及子页截图。1440×900 与 390×844 各只有一套可见主导航，选中态正确，状态标签完整，页面无横向溢出、文字重叠或底栏遮挡。 |

## 验收口径

- 截图对照用原型和具有等价字段的测试数据。至少涵盖有数据、空态、离线及旧内容，以免把真实数据与演示样例之间的差别计为界面问题。
- 桌面在隔离的真实 DSH 中亲自操作，另取 390×844 的窄屏证据。每一批记录操作路径、可见结果和必要截图。视觉通过需同时满足页面结构、主次、控件位置和状态表达。脚本通过可以作为功能证据。
- 发布、收发、标读和私有记忆写入使用隔离双节点。缺失或无法执行的场景明确登记实际限制。
- 本计划沿用已确认的产品边界。运行状态来自真实工具调用，暂停／继续和自动权限开关暂缓，聊天图片和手动切换为 Agent 发送仍暂缓。原型展示的故事、插画和时间线内容只作设计参考。
